# Критический Аудит premium.html

## 🔴 КРИТИЧЕСКИЕ ПРОБЛЕМЫ

### 1. ЦВЕТОВАЯ СХЕМА (СОВЕРШЕННО НЕПРАВИЛЬНАЯ)
**Проблема**: Текущие цвета (#667eea фиолетовый + #764ba2 пурпурный) совсем не подходят для индустриальной логистики
**Текущие цвета**:
- Login gradient: #667eea → #764ba2 (стартап-like, не профессиональное)
- Primary button: #667eea (блеклый синий)
- Text: #2c3e50 (неплохо, но общий стиль не созвучен)
- Background: #f8f9fa (слишком светлый, серый)

**Требуемые цвета (Титан2 - индустриальный стиль)**:
- Primary: #0B3D5D (глубокий темно-синий - мощный, солидный)
- Secondary: #E67E22 (теплый оранжевый - энергичный)
- Accent: #FF6B35 (яркий оранжевый - привлечение внимания)
- Background: #F5F7FA (светлее, чище)
- Text: #2C3E50 (остаётся)
- Borders: #D5DBEA (согласованнее)

**Влияние**: Текущий дизайн выглядит как стартап, а не солидная логистическая компания

---

### 2. СТРУКТУРА ФОРМ (ОШИБКИ В ВЁРСТКЕ)
**Проблема 1**: Form labels НЕ отображаются правильно в формах
```html
<!-- НЕПРАВИЛЬНО -->
<div class="form-group">
  <label>ACID</label>
  <input type="text" name="acid">
</div>
```
- Лабель стоит ДО инпута (visually читается нормально, но в CSS может быть проблема)
- Нет aria-label для доступности

**Проблема 2**: Типы полей НЕПРАВИЛЬНЫЕ
- "Дата" - используется `<input type="text">` вместо `<input type="date">` 
- "Сумма" - используется `<input type="number">` хорошо, но без step/min/max
- "Статус" - используется `<input type="text">` вместо `<select>`
- "Контагент" - свободный текст, должен быть выпадающий список или autocomplete

**Проблема 3**: Обязательные поля
- Нет `required` атрибутов
- Нет validation UI
- Нет error messages
- Можно отправить пустую форму → will crash backend

**Проблема 4**: Placeholder vs Label
- Используются placeholder'ы вместо label'ей ("Описание груза", "ACID ID")
- Когда юзер начинает печатать, label исчезает → потеря контекста
- Нарушает UX лучшие практики

### 3. ТИПОГРАФИКА (СЛИШКОМ МЕЛКАЯ)
**Текущие размеры**:
- Body text: 13px (слишком мелкий)
- Button: 14px (мелкий)
- Input: 13px (мелкий, плохо читается на мобильном)
- Heading: 18px (маловат для section heading)

**Требуемое**:
- Body text: 14px-15px (минимум)
- Input: 14px (минимум)
- Button: 14px-16px (хорошо)
- H2: 20px-22px (ясно видно)
- Label: 13px → 14px

**Влияние**: На мобильных (особенно в Египте с 3G) текст почти нечитаемый

---

### 4. ТАБЛИЦЫ (ПЛОХАЯ ЧИТАЕМОСТЬ)
**Проблемы**:
- Шрифт 13px - слишком мелкий для таблиц
- Строки чередуются #fafbfc и белый - едва виден переход
- Header (#f0f3f9) - почти тот же цвет, нет контраста
- Нет "sticky" header при скролле
- Padding в ячейках 12px - нормально, но строки часто переносятся
- Нет align для чисел (числа выглядят как текст)

**Требуемое**:
- Font: 14px минимум
- Header: более темный фон (контраст!), белый текст
- Alternating rows: #f9fafc и белый
- Number columns: text-align: right
- Sticky header при горизонтальном скролле

---

### 5. ДОСТУПНОСТЬ (НАРУШЕНИЯ WCAG)
**Проблемы**:
- Нет aria-label на кнопках
- Нет role="alert" на alerts
- Нет tabindex для управления клавиатурой
- Цветовой контраст: #667eea на #f8f9fa - едва видно!
- Нет description для сложных форм
- Form inputs не связаны с labels через `for/id`

**Требуемое**:
```html
<label for="acid-input">ACID</label>
<input id="acid-input" name="acid" required aria-label="ACID номер">
```

---

### 6. МОБИЛЬНАЯ ВЕРСИЯ (СЛОМАНА)
**Проблемы**:
- Tabs не скроллятся горизонтально плавно на мобильном
- Form grid: `minmax(250px, 1fr)` - 250px слишком много на мобильном
- Button width: 100% - OK, но padding 12px → маловат на touch
- Table: overflow-x auto, но нет scroll indicators

**Требуемое**:
- Touch targets: минимум 44px × 44px (text button)
- Form grid на мобильном: все в один столбец
- Tabs: исключить non-scrolling content
- Table: более агрессивный horizontal scroll

---

### 7. ПРОИЗВОДИТЕЛЬНОСТЬ
**Проблемы**:
- Нет lazy loading для таблиц (limit=1000 в loadData!)
- Нет пагинации (может загрузить 1000 строк!)
- Нет кэширования данных
- Каждый switchTab() делает новый запрос (даже если уже загружены)
- Нет debouncing на forms

**Требуемое**:
- Пагинация: 50 строк по умолчанию
- Кэш для каждой таблицы
- switchTab(): проверить кэш перед fetch
- Form submission: debounce 500ms

---

### 8. ОШИБКИ В КОДЕ
**Проблема 1**: loadData() не различает таблицы для ACID трех типов
```javascript
// Сейчас: все acid_* таблицы тредятся как ACID main
if (table === 'acid_main') { ... }
// Нужно: 
if (table.startsWith('acid_')) { ... }
```

**Проблема 2**: Нет fallback для пустых данных в таблицах
- acid_logistics_table - может быть undefined
- Будет ошибка: "Cannot read property 'querySelector' of null"

**Проблема 3**: Delete button inline onclick
```javascript
// ПЛОХО:
onclick="deleteRecord('${table}', '${row.id}')"
// ХОРОШО:
const btn = document.createElement('button');
btn.addEventListener('click', () => deleteRecord(table, row.id));
```

**Проблема 4**: Нет обработки HTTP errors
```javascript
if (!res.ok && res.status !== 201) throw new Error('API Error: ' + res.status);
// Просто "API Error: 400" - непонятно что случилось
```

### 9. ЛОГИКА БИЗНЕСА (НЕПРАВИЛЬНАЯ)
**Проблема 1**: Нет связей между таблицами
- ACID создается, но не связывается с контрактом (нет kontract_id в форме)
- Logistika добавляется отдельно, но не знает, к какому ACID относится
- KTI добавляется отдельно, потом нужно вручную линковать

**Требуемое**: Главная форма ACID должна показывать related логистику/таможню inline

**Проблема 2**: Контрактные типы не влияют на форму
- "Строительство" требует других полей, чем "Поставка"
- Сейчас форма одна для всех типов → путаница

**Требуемое**: Dynamic form based on tip_kontrakta

**Проблема 3**: Этапы договора не показывают статус выполнения
- Нет visual pipeline stages
- Нет timeline view

### 10. ДИЗАЙН СИСТЕМЫ (НЕПОСЛЕДОВАТЕЛЕН)
**Проблемы**:
- Spacing не унифицирован (12px, 16px, 20px, 24px везде разные)
- Border radius: 6px, 8px, 10px, 12px - не система
- Shadow: разные shadow'ы в разных местах
- Color inconsistency: #667eea, #5568d3, #dc3545 - не система

**Требуемое**: Design system (Figma-like)
- Spacing: 4px, 8px, 16px, 24px (multiples of 4)
- Border radius: 4px (small), 8px (medium), 12px (large)
- Shadow: 1 standard shadow
- Colors: 5-7 основных
