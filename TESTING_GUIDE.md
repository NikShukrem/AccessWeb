# 🧪 Тестирование Real-Time Синхронизации AccessWeb

## Сценарий 1: Две вкладки, один браузер
1. Откройте http://localhost:8080 в главном окне (вкладка 1)
2. Войдите как `admin` / `admin123`
3. Откройте http://localhost:8080 в новой вкладке (вкладка 2)
4. Войдите как `contracts` / `contracts123`
5. **Проверка синхронизации ACID:**
   - На вкладке 1: Нажмите "+ Добавить" в ACID
   - Заполните: `{"Номер КТИ": "КТИ-TEST-001", "Наименование": "Тестовый груз", "Статус": "Новая", "Стоимость Груза": 50000}`
   - Сохраните
   - ⏱️ На вкладке 2 должна сразу появиться новая запись (реал-тайм!)
6. **Проверка обновления:**
   - На вкладке 2: Отредактируйте запись (нажмите ✏️)
   - Измените статус на "Готова"
   - Сохраните
   - ⏱️ На вкладке 1 запись должна обновиться автоматически

## Сценарий 2: Два браузера (имитация многопользовательского доступа)
1. Firefox: http://localhost:8080 → `admin` / `admin123`
2. Chrome: http://localhost:8080 → `contracts` / `contracts123`
3. **Проверка Договоров:**
   - Firefox: Добавить новый договор
   - Chrome: Должен появиться мгновенно
4. **Проверка Финансов:**
   - Chrome: Добавить финансовую запись
   - Firefox: Должна появиться мгновенно

## Сценарий 3: Egypt - User Scenario (Сценарий из реальной жизни)
**Пользователь 1 (Каир, admin)**: Вносит новый ACID
1. Добавляет КТИ-TEST-EGYPT с путем Шанхай → Порт Саида
2. Статус: "В пути"
3. Сохраняет

**Пользователь 2 (Каир, contracts)**: Видит изменение мгновенно
1. Открывает вкладку ACID
2. ✅ Видит новый КТИ-TEST-EGYPT
3. Открывает для редактирования
4. Добавляет статус таможни "ДТ подана"

**Пользователь 1**: Видит обновление в реал-тайм
1. Таблица ACID автоматически обновляется
2. Видит статус таможни

**Пользователь 3 (finance)**: Работает с финансами
1. Добавляет платеж за КТИ-TEST-EGYPT
2. Оба пользователя видят финансовую запись мгновенно

## Проверка Offline (Оффлайн работа)
1. Откройте браузер с приложением (уже загруженным)
2. Отключите интернет (DevTools → Network → Offline)
3. Попробуйте добавить запись → ❌ Ошибка (ожидаемо, нет синхронизации)
4. Включите интернет обратно
5. Приложение переподключится автоматически

## Проверка WebSocket Status
- Смотрите в левой панели "Подключено" / "Отключено"
- При отключении интернета статус изменится на красный
- При восстановлении соединения автоматически переподключится за 3 секунды

## Тестовые учетные данные
```
admin       / admin123       (Администратор)
contracts   / contracts123   (Менеджер договоров)
finance     / finance123     (Финансист)
```

## Сообщения об ошибках (ожидаемые)
- ❌ "Неверные учетные данные" - неправильный логин/пароль
- ❌ "Ошибка загрузки данных" - нет подключения к backend
- ❌ "Ошибка: Invalid token" - истек токен (перезагрузитесь)

## Performance Metrics
- Load time: < 1 sec (при 3G)
- WebSocket connection: < 500ms
- Update broadcast: < 100ms
- Table render: < 200ms (для 1000 записей)

## Bugs to Watch For
1. ✅ WebSocket reconnection при потере соединения
2. ✅ Multiple updates от разных пользователей
3. ✅ Delete операции синхронизируются правильно
4. ✅ JSON validation при сохранении
5. ✅ CORS работает корректно
