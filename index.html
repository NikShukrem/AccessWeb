Отчёты

Соберите отчёт из готовых блоков (таблица, поля, условия, сортировка) — SQL сформируется сам и его можно доработать вручную. Результат сразу таблицей, запрос можно сохранить и запускать повторно.

Конструктор — соберите отчёт из блоков

Каждое условие сузит список строк. Оставите поле значения пустым — условие просто не применится. «Содержит» ищет подстроку внутри текста, «пусто» / «не пусто» — заполнено ли поле, значение для них не нужно. Для полей со статусом/типом значение выбирается из готового списка — так нельзя ошибиться в написании.
