# AccessWeb - Веб-аналог Microsoft Access

Профессиональное веб-приложение для управления базами данных с оптимизацией на медленный интернет (3G/Edge).

## 🚀 Возможности

- **Три основные таблицы**: ACID, Договоры, Финансы
- **Полный CRUD**: Создание, чтение, обновление, удаление записей
- **Импорт данных**: JSON, CSV форматы с автоматическим определением таблицы
- **Оффлайн работа**: Все данные хранятся в IndexedDB, синхронизация при подключении
- **Поиск и фильтрация**: По любым столбцам, с сортировкой
- **Экспорт в Excel**: CSV формат для совместимости
- **Умные оповещения**: Автоматическое выявление просроченных договоров
- **Расчёт валют**: Автоматический перевод в USD (EGP, EUR, RUB)
- **Виртуализация**: Ленивая загрузка строк для больших таблиц (50+ строк за раз)
- **Минимальный размер**: Single-file решение, быстрая загрузка даже на 3G

## 📦 Установка

1. Откройте `index.html` в браузере (Chrome, Firefox, Safari, Edge)
2. Приложение автоматически создаст IndexedDB при первой загрузке

## 📥 Импорт данных

### Вариант 1: JSON
```json
{
  "meta": {
    "exchangeRates": {
      "rates": { "EGP": 1, "EUR": 35, "RUB": 0.35 }
    }
  },
  "data": [
    { "ACID": "001", "Грузоотправитель": "...", ... },
    { "Номер": "C-001", "Контрагент": "...", ... }
  ]
}
```

### Вариант 2: CSV
Сохраните таблицу Excel как CSV (utf-8) и загрузите через кнопку "📥 Импорт базы"

## 📋 Структура таблиц

### ACID (40 столбцов)
Отслеживание грузов, контейнеров, таможни, поставки в Египет

**Ключевые столбцы**: ACID, Номер КТИ, Статус, ETA, DO, № ДТ

### Договоры (19 столбцов)
Управление контрактами, сроки, лимиты, статусы

**Ключевые столбцы**: Номер, Контрагент, Окончание, Статус (красное выделение при просрочке)

### Финансы (15 столбцов)
Учёт расходов с автоматическим расчётом USD

**Ключевые столбцы**: Номер КТИ, Валюта, Сумма, Перевод в USD, Договор

## 💡 Особенности

### Работа с валютами (Финансы)
- Автоматический расчёт USD при импорте
- Используется средний курс из JSON (meta.exchangeRates)
- Уже рассчитанные суммы не пересчитываются при изменении курса

### Просроченные договоры
- Красное выделение строки если `Окончание < сегодня`
- Автоматическое уведомление при открытии таблицы
- Поле "Дата запроса освобождения", "Куратор" для отслеживания

### Оптимизация для медленного интернета
- Одноф HTML файл (все inline)
- Ленивая загрузка 50 строк за раз
- Кэширование в IndexedDB (полностью оффлайн после первой загрузки)
- Минимальный размер = максимальная скорость

## 🔄 Синхронизация между таблицами

Автоматические связи по ключам:
- **ACID ↔ Финансы**: Через "Номер КТИ"
- **Финансы ↔ Договоры**: Через "Договор" (номер)
- **ACID ↔ Договоры**: Через "Контракт"

## 🎯 Примеры использования

### Добавить новую запись
1. Перейти на вкладку
2. Нажать "+ Добавить"
3. Заполнить форму
4. Сохранить (автоматически в IndexedDB)

### Импортировать данные из Access
1. В Access: Экспортировать таблицу → CSV или JSON
2. В AccessWeb: "📥 Импорт базы" → Выбрать файл
3. Данные автоматически распределятся по таблицам

### Найти просроченный договор
1. Открыть "Договоры"
2. Красные строки = просроченные
3. Отсортировать по "Окончание" для быстрого поиска

### Экспортировать в Excel
1. Выбрать таблицу, применить фильтры (опционально)
2. "📤 Экспорт в Excel"
3. CSV файл скачается на компьютер

## ⚡ Производительность

На 3G интернете (2Mbps):
- **Загрузка**: < 2 сек
- **Импорт 1000 записей**: < 1 сек
- **Поиск по 10000 строк**: < 100ms
- **Работа оффлайн**: Неограниченно (IndexedDB)

## 🔒 Безопасность

- Все данные хранятся локально в браузере (IndexedDB)
- Нет отправки на сервер (полностью оффлайн-first)
- Рекомендуется использовать HTTPS при синхронизации

## 🆘 Проблемы

### IndexedDB не работает?
- Проверьте "Приватный режим" браузера (отключает IndexedDB)
- Попробуйте другой браузер
- Очистите кэш браузера

### Импорт не распознаёт таблицу?
- Убедитесь, что в JSON/CSV есть хотя бы один ключевой столбец:
  - ACID: "ACID", "Номер КТИ"
  - Договоры: "Номер", "Контрагент"
  - Финансы: "Дата расхода", "Валюта"

### Курсы валют не обновляются?
- Добавьте новые курсы в JSON при импорте (meta.exchangeRates)
- Старые записи остаются с теми же курсами (по дизайну)

## 📞 Поддержка
