# 📂 AccessWeb - Полный список файлов проекта

## Основные файлы приложения

### ⭐ index.html (47 KB) - ГЛАВНЫЙ ФАЙЛ
**Что это?** Всё приложение в одном файле.

**Содержит:**
- HTML разметка (3 таблицы, sidebar, модали)
- CSS стили (темная панель, светлый контент, адаптивность)
- JavaScript функции (CRUD, поиск, импорт, валюты)
- IndexedDB операции (полностью оффлайн)
- Service Worker регистрация

**Размер:**
- Неминимизированный: 47.9 KB
- После gzip: ~10 KB
- Время загрузки на 3G: 2-5 сек

**Как использовать:**
```
Откройте в браузере:
- file:///C:/Users/miair/AccessWeb/index.html (прямой)
- http://localhost:8000 (сервер)
```

---

### sw.js (1.25 KB) - Service Worker
**Что это?** Обеспечивает работу оффлайн после первой загрузки.

**Функции:**
- Кэширует HTML, CSS, JS
- Network-first стратегия (сеть → кэш → оффлайн)
- Автоматически регистрируется из index.html

**Как проверить:**
- DevTools → Application → Service Workers

## Примеры данных (для импорта)

### example-data.json (3.76 KB) - Данные ACID
**Что это?** Пример 2 грузов для импорта в таблицу ACID.

**Структура:**
```json
{
  "meta": {
    "exchangeRates": { ... }  // Курсы валют
  },
  "data": [ ... ]  // Массив записей
}
```

**Как использовать:**
1. Откройте index.html
2. Нажмите "📥 Импорт базы"
3. Выберите тип "JSON"
4. Загрузите этот файл

---

### contracts-example.csv (1.49 KB) - Данные Договоров
**Что это?** CSV с примерами 5 договоров.

**Структура:**
```
Номер,Предмет,Контрагент,Тип,Статус,...
CONTRACT-001,Услуги логистики,Partner A,Service,Active,...
...
```

**Как использовать:**
1. Откройте в Excel
2. Отредактируйте данные (опционально)
3. Сохраните как CSV (UTF-8)
4. Импортируйте в AccessWeb

---

### finance-example.csv (1 KB) - Данные Финансов
**Что это?** CSV с примерами 5 финансовых записей.

**Структура:**
```
Дата,Номер КТИ,Валюта,Сумма,Договор,...
2026-04-20,KTI-2026-001,EGP,15000,CONTRACT-001,...
...
```

**Особенность:**
- При импорте автоматически рассчитывается USD
- Если Валюта = EGP, EUR, RUB → преобразуется в USD
